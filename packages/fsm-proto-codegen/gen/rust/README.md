# pgfsm-proto-codegen

Generated [prost](https://crates.io/crates/prost) messages +
[tonic](https://crates.io/crates/tonic) client/server stubs for
[pgfsm](https://github.com/pgfsm/fsm)'s Activity Gateway
(`pgfsm.activitygateway.v1`) and Sidecar Gateway (`pgfsm.sidecargateway.v1`)
contracts.

```toml
[dependencies]
pgfsm-proto-codegen = "0.1"
# prost, tonic and tonic-prost must all share one major (0.14 here) — mixing
# majors fails with a "two different versions of crate `prost`" error.
```

```rust
use pgfsm_proto_codegen::pgfsm::activitygateway::v1 as activity_gateway;
use pgfsm_proto_codegen::pgfsm::sidecargateway::v1 as sidecar_gateway;
```

Generated by `buf generate` from the `.proto` sources in
[`packages/fsm-proto-codegen`](https://github.com/pgfsm/fsm/tree/main/packages/fsm-proto-codegen)
— don't edit, regenerate. The same contracts are published for TypeScript
(`@pgfsm/proto-codegen` on npm), Python (`pgfsm-proto-codegen` on PyPI), and Go
(`github.com/pgfsm/fsm/packages/fsm-proto-codegen/gen/go`), all at the same
version.
