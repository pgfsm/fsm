# github.com/pgfsm/fsm/packages/fsm-proto-codegen/gen-sync/go

Generated protobuf + gRPC stubs for [pgfsm](https://github.com/pgfsm/fsm)'s the
Sync Executor contract (`pgfsm.syncexecutor.v1`): the stream between the fsmlet
engine and the per-language executors that run an FSM's actions, guards, delays
and input mappers
([SPEC-018](https://github.com/pgfsm/fsm/blob/main/docs/specs/spec-018-sync-operation-executors.md)).

```sh
go get github.com/pgfsm/fsm/packages/fsm-proto-codegen/gen-sync/go@latest
```

```go
import syncexecutorv1 "github.com/pgfsm/fsm/packages/fsm-proto-codegen/gen-sync/go/syncexecutor/v1"
```

Released by git tag `packages/fsm-proto-codegen/gen-sync/go/vX.Y.Z` (no registry
upload — the Go module proxy serves it from the tag). Generated by
`buf generate` from the `.proto` sources in
[`packages/fsm-proto-codegen`](https://github.com/pgfsm/fsm/tree/main/packages/fsm-proto-codegen)
— don't edit, regenerate. The same contract is published for TypeScript
(`@pgfsm/proto-codegen-sync` on npm) and Python/Rust (`pgfsm-proto-codegen-sync`
on PyPI / crates.io), all at the same version. The Activity Gateway and Sidecar
Gateway contracts are published separately, as `@pgfsm/proto-codegen` /
`pgfsm-proto-codegen` and
`github.com/pgfsm/fsm/packages/fsm-proto-codegen/gen/go`, with their own
version.
