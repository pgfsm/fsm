# pgfsm-proto-codegen-sync

Generated protobuf + gRPC stubs for [pgfsm](https://github.com/pgfsm/fsm)'s the
Sync Executor contract (`pgfsm.syncexecutor.v1`): the stream between the fsmlet
engine and the per-language executors that run an FSM's actions, guards, delays
and input mappers
([SPEC-018](https://github.com/pgfsm/fsm/blob/main/docs/specs/spec-018-sync-operation-executors.md)).

```sh
pip install pgfsm-proto-codegen-sync
```

```python
from pgfsm.syncexecutor.v1 import sync_executor_pb2, sync_executor_pb2_grpc
```

Generated by `buf generate` from the `.proto` sources in
[`packages/fsm-proto-codegen`](https://github.com/pgfsm/fsm/tree/main/packages/fsm-proto-codegen)
— don't edit, regenerate. The same contract is published for TypeScript
(`@pgfsm/proto-codegen-sync` on npm), Rust (`pgfsm-proto-codegen-sync` on
crates.io), and Go
(`github.com/pgfsm/fsm/packages/fsm-proto-codegen/gen-sync/go`), all at the same
version. The Activity Gateway and Sidecar Gateway contracts are published
separately, as `@pgfsm/proto-codegen` / `pgfsm-proto-codegen` and
`github.com/pgfsm/fsm/packages/fsm-proto-codegen/gen/go`, with their own
version.
