# pgfsm-proto-codegen-sync

Generated [prost](https://crates.io/crates/prost) messages +
[tonic](https://crates.io/crates/tonic) client/server stubs for
[pgfsm](https://github.com/pgfsm/fsm)'s the Sync Executor contract
(`pgfsm.syncexecutor.v1`): the stream between the fsmlet engine and the
per-language executors that run an FSM's actions, guards, delays and input
mappers
([SPEC-018](https://github.com/pgfsm/fsm/blob/main/docs/specs/spec-018-sync-operation-executors.md)).

```toml
[dependencies]
pgfsm-proto-codegen-sync = "0.1"
# prost, tonic and tonic-prost must all share one major (0.14 here) — mixing
# majors fails with a "two different versions of crate `prost`" error.
```

```rust
use pgfsm_proto_codegen_sync::pgfsm::syncexecutor::v1 as sync_executor;
```

Generated by `buf generate` from the `.proto` sources in
[`packages/fsm-proto-codegen`](https://github.com/pgfsm/fsm/tree/main/packages/fsm-proto-codegen)
— don't edit, regenerate. The same contract is published for TypeScript
(`@pgfsm/proto-codegen-sync` on npm), Python (`pgfsm-proto-codegen-sync` on
PyPI), and Go (`github.com/pgfsm/fsm/packages/fsm-proto-codegen/gen-sync/go`),
all at the same version. The Activity Gateway and Sidecar Gateway contracts are
published separately, as `@pgfsm/proto-codegen` / `pgfsm-proto-codegen` and
`github.com/pgfsm/fsm/packages/fsm-proto-codegen/gen/go`, with their own
version.
